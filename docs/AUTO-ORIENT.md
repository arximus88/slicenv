# Автоорієнтація

Q або «Автоорієнтація (Q)» на плаваючій панелі орієнтує вибрані інстанси;
без вибору — усі інстанси активної пластини. Це одноразова дія, активний
інструмент не перемикається. `Workspace::orient_plate(index, cx)` приймає
нульовий індекс пластини, як `show_plate`.

`project::orient::best_rotation(mesh, &OrientParams)` повертає додатковий
найкоротший поворот до обраної вертикалі. Окремої оптимізації повороту навколо
Z немає. Кандидати: поточна орієнтація, нормалі опуклого корпуса (існуючий
Quickhull), великі грані моделі, координатні осі та 48 напрямків сфери Фібоначчі.
Основа — підхід OrcaSlicer AutoOrienter / OrientMesh:
https://github.com/SoftFever/OrcaSlicer/blob/main/src/libslic3r/Orient.cpp
Це спрощена оцінка, а не повне відтворення його target_function чи оптимізації
напрямку охолодження.

Вартість = площа нависань − 0.5 × площа контакту +
0.02 × загальна площа × висота / діагональ. Типовий кут нависання — 45°,
товщина контактного шару — 0.2 мм. Контактні грані не рахуються як нависання.
При рівній вартості зберігається поточна орієнтація. Для обмеження часу
обчислень використано до 8192 трикутників (із поправкою площі на частоту
вибірки), до 2048 точок корпуса й до 32 основних нормалей корпуса.
Малі деталі великої сітки можуть не потрапити у вибірку.

`Project::orient_instance` враховує масштаби, відбиття та трансформації частин,
ігнорує модифікатори й негативні об’єми, обертає весь інстанс навколо його
центра та опускає на стіл за повними габаритами. Геометрія інших інстансів
спільного об’єкта не змінюється.

У UI розрахунок виконується background executor на snapshot. Перед застосуванням
перевіряються ревізія геометрії, поточний snapshot і активні перетягування.
Застарілий результат відкидається. Застосування всієї групи атомарне, з одним
checkpoint «Автоорієнтація» та стандартним скиданням нарізки / оновленням сцени.
Поки триває розрахунок, панель показує статичний текст.

Тести в `crates/project/src/orient.rs`: куб на ребрі, збереження вже оптимальної
орієнтації та yaw, нахилений циліндр, L-кронштейн без нависань, опускання
інстансу на стіл / ізоляція іншого інстансу, порожня сітка. Окремий ignored-тест
`half_million_triangles_timing` вимірює 504300 трикутників у release:

```sh
CARGO_TARGET_DIR=~/.cache/bambu-target-orient cargo test --workspace
CARGO_TARGET_DIR=~/.cache/bambu-target-orient cargo test -p project --release half_million_triangles_timing -- --ignored --nocapture
```

Перевірка 2026-11-03: шість функціональних тестів автоорієнтації пройшли
в release. Ядро `best_rotation` на синтетичній сітці з 504300 трикутників
(деталізовані грані куба) виконалося за 34.50 мс, повний `orient_instance` із трансформаціями й
опусканням на стіл — за 43.59 мс. Побудова тестової сітки в цей час
не входить. Це вимір одного типу геометрії, а не гарантія для кожної моделі.

Фінальний `cargo test --workspace`: 198 passed, 0 failed, 3 ignored,
включно з doctest; performance-тест окремо запущено в release.
Бінарник `slicenv` зібрано в тому самому заданому target-каталозі.
