# Slicenv 0.1.2

## What's new
- **No more false engine warning after slicing.** Slicenv showed "Engine warning: no substitutions performed from file …" after every slice. That line in the OrcaSlicer log reports that nothing was substituted, so it is no longer shown.
- **Arch Linux packages** are now on the AUR: [`slicenv-bin`](https://aur.archlinux.org/packages/slicenv-bin) and [`slicenv-git`](https://aur.archlinux.org/packages/slicenv-git).
- Test data and documentation no longer contain machine-specific names and addresses.

Everything from [0.1.1](https://github.com/arximus88/slicenv/releases/tag/v0.1.1) is included: project tabs, the floating project bar, the new printer connection flow and the single Print button.

## Known limits
- Slicing runs only in the active tab: until it finishes you cannot switch tabs or open another file.
- Closing the window does not ask about unsaved changes in tabs.
- This release ships Linux x86_64 builds only. Windows and macOS builds were not made or tested; 0.1.0 remains the latest for those platforms.
