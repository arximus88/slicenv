## What's new
- **GNOME window controls follow your system settings** and update without a restart: the button layout (minimize, maximize, which side) and the double-, middle- and right-click actions on the header bar set in GNOME Tweaks.
- The explanation of why the cloud camera is unavailable is shown in the interface language (it used to stay in Ukrainian in the English interface).
- **Unsaved preset changes dialog** when switching engines: long values such as G-code are shortened to the start of the first line and no longer spill over the buttons; the engine name is shown instead of a file path.
- New screenshots in the app description: the GNOME look, tabs, OrcaSlicer 2.5.0.
- The test suite now passes on macOS (both architectures) and Windows; the Flatpak passes the Flathub linter.

### First launch on macOS
The build is not signed with an Apple Developer ID and is not notarized, so macOS blocks it. Open it once, press Done, then go to **System Settings → Privacy & Security** and press **Open Anyway** next to Slicenv. Or run `xattr -dr com.apple.quarantine /Applications/Slicenv.app`. The same steps are in "Read Me First.txt" inside the disk image.

On Windows, SmartScreen warns about an unknown publisher: **More info → Run anyway**.

## Known limits
- In the GNOME look, clicking, dragging and double-clicking the header bar were not tested with a real mouse.
- The translated camera explanation was checked by a test only, not with a real printer.
- The macOS builds are not signed and were not run on a real Mac; the Windows build is not signed (the 0.1.4 Windows build was tested on a real machine: install, slicing with OrcaSlicer 2.5.0, Bambu Connect handoff and printing).
- Slicing runs only in the active tab; closing the window does not ask about unsaved changes in tabs.
