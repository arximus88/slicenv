# Slicenv 0.1.3

## What's new
- **OrcaSlicer 2.5 profiles without a download.** They are read from the engine package itself, instantly and offline. Before, "Downloading profiles · 0 / 2496" could hang forever after installing OrcaSlicer 2.5.0. The GitHub download remains as a fallback and no longer stalls on networks where IPv6 never completes TLS.
- **The app says what is missing.** With no slicing engine, the Slice button becomes **Install engine** and opens the installer; the Preview card and the profile panel say the same instead of "Profiles are still loading…".
- **Print without a connected printer.** Print now hands the sliced file to **Bambu Connect** or opens it in an installed **Bambu Studio**. This is the way to print over the cloud on macOS.
- **The model library no longer scans your whole home folder.** Until you pick a folder it is empty. On macOS this removes the prompts for Music, Photos and Desktop access.
- Bambu Studio 02.09 packages are labelled Ubuntu 22.04 / 24.04, and the setup wizard picks the 24.04 build.
- Everything from [0.1.1](https://github.com/arximus88/slicenv/releases/tag/v0.1.1) and [0.1.2](https://github.com/arximus88/slicenv/releases/tag/v0.1.2): project tabs, the floating project bar, the new printer connection flow.

### First launch on macOS
The build is not signed with an Apple Developer ID and is not notarized, so macOS blocks it. Open it once, press Done, then go to **System Settings → Privacy & Security** and press **Open Anyway** next to Slicenv. Or run `xattr -dr com.apple.quarantine /Applications/Slicenv.app`. The same steps are in "Read Me First.txt" inside the disk image.

On Windows, SmartScreen warns about an unknown publisher: **More info → Run anyway**.

## Known limits
- The macOS and Windows builds were built and smoke-tested in CI only. The Bambu Connect and Bambu Studio handoff was not tested on a real Mac.
- Bambu Cloud sign-in, status and camera are not available on macOS (the Bambu network plugin is not loaded there); LAN works.
- Slicing runs only in the active tab; closing the window does not ask about unsaved changes in tabs.
