# Slicenv 0.1.1

## Зміни

- Вкладки відкритих проєктів: кілька файлів одночасно, кожна вкладка зберігає модель, історію скасування, профілі, камеру й нарізки. Ctrl+Tab / Ctrl+Shift+Tab перемикають, Ctrl+W закриває.
- Режими Prepare / Preview / Project і дії «Зберегти», «Нарізати», «Друкувати» — на плаваючій панелі над сценою; вона не зсувається від бічних панелей і перемикання режимів.
- Підключення принтерів: один список і діалог додавання, пошук і прокрутка для багатьох пристроїв; зрозумілі стани входу, підключення й помилок.
- Необов’язковий Open Bamboo Networking на Linux за явним вибором користувача: друк через LAN і Bambu Cloud. Плагін не входить у пакети Slicenv.
- Захист від витоку секретів через логи OBN: налаштування без логування передаються до створення агента, включно з бібліотекою камери.
- Одна кнопка «Друкувати», видимий маршрут і можливість його змінити. Застарілий LAN-запис більше не витісняє готове хмарне підключення; явний маршрут не підміняється.
- Помірний контраст світлої теми: світліші поля, м’які рамки та виразніший текст. У налаштуваннях видно джерело застосованої теми; наслідування Omarchy збережено.
- Поліпшення багатопластинного Preview, швидкості нарізки, фоторежиму та підтримки Klipper/Moonraker.
- Обмеження розпакування 3MF для захисту від zip-бомб.

## Перевірка

- Повна перевірка злитих функціональних змін: 593 тести успішні, 0 падінь; clippy й переклади пройшли.
- Вкладки й плаваючу панель пройдено сценарієм в ізольованому вікні.
- Користувач підтвердив справжній друк через хмару з відкритим плагіном.
- Відсутність витоку логів перевірено синтетичним плагіном; справжній OBN із сесією користувача в тестах не запускався.

## Відомі межі

- Нарізка йде лише в активній вкладці: до її завершення перейти на іншу вкладку чи відкрити ще файл не можна.
- Закриття вікна не питає про незбережені зміни у вкладках.
- OBN може вивести один рядок із власною версією під час завантаження бібліотеки; він не містить даних акаунта чи принтера.
- Вибраний маршрут друку запам’ятовується до закриття застосунку.
- Після виходу із закритого плагіна може бути доступна сесія Bambu Studio / OrcaSlicer.
- macOS і Windows не перевірялися в межах цього випуску; можливості відкритого плагіна тут стосуються Linux.
