# Slicenv 0.1.1

## What's new
- **Project tabs.** Several files can be open at once. Each tab keeps its model, undo history, profiles, camera and slices. Ctrl+Tab / Ctrl+Shift+Tab switch tabs, Ctrl+W closes one.
- **Floating project bar.** Prepare / Preview / Project and the Save, Slice and Print actions sit on a bar above the scene; it stays in place when side panels open or the mode changes.
- **Printer connections.** One list and one add dialog, with search and scrolling for many devices, and clearer sign-in, connection and error states.
- **One Print button** with a visible route that you can change. A stale LAN entry no longer overrides a ready cloud connection.
- **Optional Open Bamboo Networking on Linux**, only by explicit user choice: printing over LAN and Bambu Cloud. The plugin is not shipped with Slicenv, and its logging is disabled before it starts so that secrets cannot leak into logs.
- **Light theme** with moderate contrast: lighter fields, softer borders, clearer text.
- Better multi-plate Preview, faster slicing, Photo mode improvements, and Klipper/Moonraker support.
- 3MF unpacking limits to guard against zip bombs.

## Known limits
- Slicing runs only in the active tab: until it finishes you cannot switch tabs or open another file.
- Closing the window does not ask about unsaved changes in tabs.
- The chosen print route is remembered until the app closes.
- This release ships Linux x86_64 builds only. Windows and macOS builds were not made or tested for 0.1.1; 0.1.0 remains the latest for those platforms.
