## What's new
- **Reworked Send to printer dialog.** Pick the printer from a large card list with a photo of each model; print time and filament weight stand out; every way of sending is visible at once together with its state.
- If the file was sliced for a different printer model, the dialog explains this and does not send it directly (Bambu Connect stays available).
- **Pre-print options** (bed levelling, flow, vibration calibration, timelapse) show only what the model supports and are remembered per printer.
- **GNOME look:** rounded window corners (15 px, as in libadwaita), window button glyphs that match the system, and equal height of buttons and tabs in the header bar.
- A **+** button after the last tab opens a new project.
- Cloud camera: error 403 is explained as a Bambu Lab restriction instead of advice to check the printer.
- A number written differently ("1" vs "1.0") no longer marks a profile as modified after opening a project from another engine.

### First launch on macOS
The build is not signed with an Apple Developer ID and is not notarized, so macOS blocks it. Open it once, press Done, then go to **System Settings → Privacy & Security** and press **Open Anyway** next to Slicenv. Or run `xattr -dr com.apple.quarantine /Applications/Slicenv.app`. The same steps are in "Read Me First.txt" inside the disk image.

On Windows, SmartScreen warns about an unknown publisher: **More info → Run anyway**.

## Known limits
- The window frame is drawn by a patched copy of gpui-component 0.8.1 (`vendor/`); updating the library means carrying the patch over.
- AMS slot mapping is not supported in the print dialog.
- The printer list in the dialog cannot be operated with the keyboard.
- The macOS builds are not signed and were not run on a real Mac; the Windows build is not signed.
- Slicing runs only in the active tab; closing the window does not ask about unsaved changes in tabs.
