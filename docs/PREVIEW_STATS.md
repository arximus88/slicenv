# Шви та статистика Preview

Панель ліворуч показує час і частку від суми показаних рядків та Travel, витрату філаменту за ролями,
переміщення та окремі перемикачі ретракту, повернення філаменту, витирання і швів.
Білі шви видимі початково; ретракт, повернення та витирання — сховані.
Маса за ролями обчислюється лише за наявності діаметра й густини в конфігу,
вартість — лише за наявності ціни. Інших локалей, крім `en.json`, зараз немає:
українська — мова вихідних ключів.

## Джерела та алгоритми

Час за ролями й повний час беруться з сусіднього `result.json`, якщо він є.
Без нього повний час береться із шапки G-code, а розподіл — із власного планувальника.
Панель явно вказує джерело. Підготовка — різниця повного часу й часу моделі із шапки;
інакше оцінка стартових рухів. Таймлапс — оцінка рухів у `SKIPTYPE: timelapse`.

Звірено з локальними `src/libslic3r/GCode/GCodeProcessor.cpp`:

- BambuStudio `79df7ae309be398ed30c9f397c13c9911c2edc57`: `process_G1`,
  `TimeMachine::calculate_time`, трапеції, M201/M203/M204/M205, `process_M400`.
- OrcaSlicer `d28c71c485cf51949c5ed4f6ee59998b7f17566c`: детектор швів, внутрішні G1 для G2/G3.

Шов реєструється після виходу із зовнішньої петлі, якщо кінець від початку ближче
0,25 мм; позиція — середина між ними. Overhang wall може продовжувати петлю.
Для spiral/scarf початок оновлюється з ростом Z. Це точніша умова, ніж будь-який
старт зовнішньої стінки після travel: незамкнена стінка не створює шва.

## Відтворення чисел

636 шарів, 832997 сегментів. SHA256:

```sh

  ~/.cache/slicenv/sliced/angel_medium-plate1/plate_1.gcode \
  ~/.cache/slicenv/sliced/angel_medium-plate1/result.json
```

Стара формула довжина/подача: Outer wall **2902,1 с (48 хв 22 с), 68,61%**,
сума лише екструзії **4229,9 с**. Вона не моделювала прискорення/гальмування,
обмеження осей і швидкість стиків коротких сегментів. Знаменник ігнорував travel,
ретракти, wipe й підготовку. Роль `Floating vertical shell` також помилково
потрапляла в Outer wall; тепер вона відповідає Internal solid infill, як у Bambu.

Власний планувальник: Outer wall **6041,8 с (1 год 41 хв)**,
Inner wall **1566,9 с**, Gap infill **581,3 с** — збігаються з `result.json`
до десятої секунди. Повний час **13530,4 с** проти **13528,53 с** рушія
(відхилення **+1,9 с / +0,014%**); раніше — **13245,5 с / −283,0 с**.
Підготовка без шапки: **384,3 с**, раніше **99,3 с**. Додано 260 с за G29

не завантажують філамент; повторний T0 також не додає часу.
Preview із `result.json` зберігає повний час **13528,53 с** та Outer wall

Детектор знайшов 35855 швів.

## Orca та межі власної оцінки

Файли `generated by OrcaSlicer` розбивають дуги на внутрішні G1: допуск
0,0125 мм, корекція обертання кожні 25 кроків; для `marlin2` — крок за
радіусом, подачею та 50 Гц (0,1–2 мм). Видима теселяція незалежна; час
внутрішніх G1 розподіляється між видимими сегментами без втрат.
Підтримано I/J, повне коло без P, P1 і R (також виправлено вибір центра R
у візуальній теселяції). P, відмінний від 1, як у Bambu не оцінюється.

Звірка Orca 2.5.0-beta: кешова нарізка
`Aero+Dock+v2+Standard-compat-plate1-876739-1793698836128772714/plate_1.gcode`
під `~/.cache/slicenv/sliced/orca/`, 186 шарів, 1238037 видимих сегментів.
Шапка: **9403 с**, власний час **7192,2 → 8732,5 с**;
відхилення **−23,51% → −7,13%**. Частки таблиці **~76% → 100%**.
Підготовка **98,7 → 383,4 с** (шапка 384 с).
Це не повний порт усіх відмінностей сучасного планувальника Orca:
залишкова різниця **−670,5 с** явно зберігається; повний час у Preview береться
із шапки, оцінка рядків позначена окремо. Багатосоплові/AMS сценарії,
термостабілізація та всі варіанти команд завантаження ще не відтворені.

Ліміти конфігу застосовуються лише для marlin/marlin2/klipper. Без них —
дефолти Bambu (XYZE: швидкість 500/500/12/120, прискорення
1000/1000/500/5000, jerk 10/10/0,2/2,5). M205 X не перекриває явний Y;
M203 RepRap переводиться з мм/хв. SET_VELOCITY_LIMIT підтримує ACCEL,
SQUARE_CORNER_VELOCITY та VELOCITY.

Unit-тести покривають повне коло/P/R, Orca проти явних внутрішніх G1,
M201/M203/M205, Klipper, G29/M622/M623, завантаження, суму часток,
spiral/scarf та відповідність кількості шарів. Референсний тест посилено:
розбіжність із повним часом Bambu має бути меншою за 3 с.
Візуальна перевірка GUI не входить у ці тести.

## Швидкодія

Release, той самий файл angel_medium у пам’яті, без файлового I/O та знищення
Toolpath, медіана серії запусків. Порівняльні копії отримано з git-об’єктів
у `target/` цього worktree, main та інші worktree не змінювалися.
Main: **115,0 мс**, 8ed5b57: **206,2 мс**, поточна версія: приблизно
**156–164 мс** (близько **1,36–1,43× main**, замість **1,79×**).
Останній контрольний прогін: **p50 156,827 мс / p95 157,987 мс**, бюджет
160 мс пройдено; синтетичний файл — **p50 88,994 мс** проти бюджету 125 мс.
Орієнтир ~156 мс відтворився, але строгий коефіцієнт ≤1,3× від виміряного
main 115 мс не досягнуто (1,36×). Під навантаженням виміряно й 164,4 мс:
запас до бюджету невеликий.

Прибрано SipHash з обліку філаменту, ролей і рухів (масиви за Role/MoveKind),
параметри G1 читаються одним проходом. У планувальнику — формула півкута
через dot, порівняння квадратів довжин, повторне використання нормалізованих
напрямків, вилучення зайвої початкової трапеції та інлайн push.
Інструментований профіль push давав 53–56 мс із накладними витратами таймера;
непридатне спрощення гальмування відкинуто, бо погіршувало звірку Bambu.

`perf` має синтетичний сценарій 800 тис. G1 (доступний у CI) і необов’язковий
`GCODE_PERF_REFERENCE`. Бюджети p50: **125 мс** для синтетичного файлу,
**160 мс** для референсного; вони задані як `max_ms` у `bench/baselines.json`.
Це машинозалежні межі, CI перевіряє лише інваріанти, як і раніше.

Референсна перевірка (зовнішні файли не включено до репозиторію):

```sh
GCODE_TIME_REFERENCE=~/.cache/slicenv/sliced/angel_medium-plate1/plate_1.gcode \
GCODE_TIME_RESULT=~/.cache/slicenv/sliced/angel_medium-plate1/result.json \
CARGO_TARGET_DIR=~/.cache/slicenv-target-ci \
cargo test -p gcode --test time_reference -- --ignored
```

## Виконані перевірки

`cargo test --workspace`, `SLICENV_REQUIRE_GPU=1 cargo test -p viewer`,
`cargo clippy --workspace --all-targets -- -D warnings` з усіма `-A` зі
змінної CLIPPY_ALLOW у CI, `python3 -I crates/app/tools/check_translations.py`,
референсний тест Bambu та `git diff --check`.
Для clippy також прибрано наявний зайвий `mut` у viewer/tests/async_render.rs.

Preview переміщено у has_left рядка стану; render вже використовує лівий док.
Кнопка всіх типів зберігає стан HIDDEN_BY_DEFAULT. Прибрано мертву гілку
Retract та невикористані ключі перекладу. «Довжина» збережено: ключ уживається
динамічно через підписи schema/options.json. Українські тексти використовують
«Таймлапс» / «таймлапс».
