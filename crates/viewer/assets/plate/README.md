# OrcaSlicer plate icons

Source: OrcaSlicer v2.5.0-beta, `resources/images/plate_*.svg` (local engine distribution),
copied unchanged. OrcaSlicer is licensed under AGPL-3.0; the upstream names and artwork
are retained. Slicenv rasterizes them into the 3D scene, on the bed plane next to the active
plate, the same way Bambu Studio / OrcaSlicer draw their plate buttons.
